# Gvtcier 功能总览

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 渲染 | 主几何管线 | PBR 风格着色：基色 tint + 高光 + 光照累加，材质与太阳参数数据驱动 |
| 渲染 | 延迟渲染 | 光照由逐物体 Forward 改为全屏统一计算（deferred_light），不透明几何先写 G-Buffer 再统一着色；透明物体仍走 Forward，Deferred + Forward 混合 |
| 渲染 | 延迟写入范围 | 延迟 shader 只输出 location 0，绘制前后以 DrawBuffer(ColorAttachment0) / DrawBuffers(4) 限定，防止未写附件覆盖几何 pass 写好的法线 |
| 渲染 | 自发光 | gMaterial.w 为 0 标记自发光（太阳 / 发光材质 / 天空），延迟 pass 直接输出 G-Buffer 颜色不做光照 |
| 渲染 | 透明通道 | Object.transparent 物体跳过不透明循环，延迟光照跑完后单独一个 pass（深度测开 / 深度写关 / SrcAlpha 混合），复用 Forward 着色代码 |
| 渲染 | 蒙皮走延迟 | skinned.vert 输出世界坐标，skinned.frag 由自算光照改为只写 G-Buffer，与静态几何统一延迟着色 |
| 渲染 | Forward+ 聚类光照 | 光源按屏幕 tile 剔除（GPU compute 构建，不可用时回退 CPU），动态光 SSBO 下发，光源池 256/1024/4096 按画质分档 |
| 渲染 | 反向 Z 深度 | 近 1 远 0：投影矩阵符号翻转、深度比较全局 Greater、清屏 0.0，主深度与级联深度用 32F 浮点格式，浮点精度集中近处大幅缓解 Z-Fighting；天空 / GTAO / HZB / 体积光守卫与比较方向全链路适配 |
| 渲染 | GTAO 环境光遮蔽 | 地平线搜索 + 解析积分（Jimenez 2016 / XeGTAO 口径）：切片沿屏幕切平面取最大遮蔽角，再对可见角区间用闭式原函数积分；主 pass 附带输出深度边缘图，去噪用十字加对角三乘三边缘感知加权（两遍串联），法线取自 G-buffer，参数全可调 |
| 渲染 | G-buffer 法线缓冲 | 主 pass 双输出（颜色 + 世界空间法线，Rgba16F），供 GTAO 采样 |
| 渲染 | CSM 级联阴影 | 太阳 4 级级联 2048×4 深度数组纹理（32F 反向 Z），对数+线性混合分割（120 米，λ=0.6），级联包围相机锚定（中心取相机位置、半径按级联远距与视口张角解析求得，只随位置平移不随朝向漂移）+ 光源空间 texel snapping；深度 pass 前背面剔除；deferred 与 forward（main / 实例化）双路 sampleCSM 采样 |
| 渲染 | ASM 并行级联阴影 | 近两级不再由主光拍大图：每个近处物体（reach 超过级联 1 或包围盒超 8 米的除外）动态下发一台子相机，以物体为中心、朝向沿用光照轴、正交盒放大 1.35 罩住影子落点、深度窗口按本级实际遮挡物沿光轴投影求真实范围；16 槽 256² 深度图集逐槽渲染，视锥内相交物体全部画入子图保证互遮挡；着色器按判定半径命中子相机则优先采子图（3×3 邻域堵贴边漏光），未命中或超槽回落 CSM |
| 渲染 | 硬阴影 | 阴影为单次深度硬比较（PCSS 软化已移除，无时域累积下多 tap 为负收益）；偏差模型：CSM 路径沿用法线偏移链，ASM 子相机与点阴影立方图因纹素极小只留沿光 epsilon（点阴影另有法线+斜率自适应偏移防痤疮） |
| 渲染 | 点光/聚光阴影 | 通用立方阴影：四张 512² 立方图存「到光源距离」（R32F，方向向量采样），每帧为前 4 盏 castShadow 点光/聚光各渲六面（90° 透视、剔正面）；光源数据步长 13 含阴影槽位，着色器按槽位比较；场景灯、特效灯、手电筒同一管线 |
| 渲染 | HDR 管线 | bright 提取 → 高斯模糊 → 合成（ACES 色调映射），bloom 强度可调；模糊用十三抽头降采样（中心四倍 + 四角一倍 + 十字两倍，除十六）与 tent 升采样（带强度系数）金字塔；天空像素（深度为清屏值）跳过曝光与色调映射直接输出原色，天空调色与场景解耦；延迟光照把阴影系数写进 HDR 颜色 alpha，合成按系数把曝光混向 1.0，阴影区亮度锚定不受曝光调整影响 |
| 渲染 | 高斯模糊双模 | blur.frag 抽头数不超过七沿用固定权重核，超出走可调半径高斯核（标准差取半径一半） |
| 渲染 | UI 毛玻璃 | glass.frag 圆角 SDF 遮罩在锐利原图与磨砂之间混合，frost 取模糊结果乘 0.94 加冷色调乘色调强度、边缘加高光；渲染器先经 RHI 读缓冲到纹理拷贝当前画面，再走降采样升采样金字塔取模糊源，面板按 z 排序 |
| 渲染 | RHI 读缓冲到纹理 | Gvtcier_Rhi_ReadBufferTex：GL 用 glCopyTexSubImage2D 把当前读缓冲直接拷进纹理（GPU 侧拷贝零回读），GLES 与 Vulkan 后端留空桩 |
| 渲染 | 暗角 | compose 末尾圆形径向衰减（屏幕中心距离平方乘系数再钳制到 0-1），设置界面「图形」页滑块 0-1，缺省 0.3，0 即关闭 |
| 渲染 | 画质选项 | 设置界面「图形」页暴露环境光遮蔽与抗锯齿两项开关，默认全开；AO 每帧同步进渲染选项，抗锯齿走 Gvtcier_Render_SetFxaa；遮挡剔除属底层优化不暴露 |
| 渲染 | 帧率档位 | 设置枚举 FrameRateMode 六档（垂直同步 / 30 / 60 / 90 / 120 / 无限制），常规页垂直同步开关合并进来；前四档关垂直同步并按目标帧时间在主循环帧尾节流（先休眠到差 1ms 再忙等收尾），无限制档不节流 |
| 渲染 | FXAA 抗锯齿 | 屏幕空间抗锯齿，脚本 / 设置界面 开关 |
| 渲染 | 二维引擎界面队列 | Render2D 先提交画布队列，再补提交引擎界面队列并清空；此前该队列在二维路径从未被绘制，暂停菜单只剩黑屏且队列无界累积 |
| 渲染 | 渲染分辨率 | 渲染分辨率(宽, 高) 离屏渲染后拉伸到窗口，独立于窗口尺寸 |
| 渲染 | 天空 | far 平面深度重建渐变天空 + 太阳，天空球半径 1999（比最大视距 2000 小 1） |
| 渲染 | 屏幕空间半球 GI | 延迟光照里对着色法线半球 12 个黄金角方向采样 G-buffer，可见表面按其自身受光（单 tap 廉价阴影测试，阴影里的暗面不污染贡献）与反照率贡献间接光，阴影死黑被环境反弹提亮；剔除判定全部在世界空间、与视角无关，亮度不随视距漂移 |
| 渲染 | 体积云 | 体积系统内的高度板层密度项（180 米层高 80，高度梯度 + 双 octave 噪声 + 覆盖阈值，向太阳采样自遮挡明暗，HG 相位银边），与体积光共用射线步进与合成通道，静止无漂移 |
| 渲染 | 后期链基调 | 中性分级：饱和度 1.05、对比度 1.0、ACES 曝光偏置 1.6、晕影 0.3，不再叠加滤镜式强化 |
| 输入 | 玩家手电筒 | F 键开关，聚光灯随相机视角（暖白 19° 半角），作为普通投影灯参与 tile 光照与立方阴影，无独立机制 |
| 渲染 | 体积光 | 光线步进体积散射，沿视线采样，含高度衰减、3D 噪声、HG 相位与阴影可见性，输出散射光柱 |
| 渲染 | 体积雾 | 在体积光步进基础上输出透射率，compose 按透射合成（hdr = 场景 × 曝光 × 透过率 + 散射），使雾能真正遮挡背景；雾额外受环境光照明，背光处不死黑 |
| 渲染 | 雾质量四档 | 无（不加雾）/ 低（屏幕空间指数高度雾）/ 中（体积雾，较低密度、较远作用距离）/ 高（体积雾，更高密度、更远距离、更多步数）；屏幕空间雾仅在「低」档启用，中高档由体积雾承担，避免叠加；体积雾与体积光开关解耦，由雾质量档位驱动 |
| 渲染 | 自动曝光 | 人眼适应模型：16×16 采样对数平均亮度（模拟人眼对数响应）测光，目标中灰 key=0.18，曝光 = key / 平均亮度；不对称时间适应（变亮快、变暗慢），对应瞳孔收缩快于扩张；不依赖阴影判定 |
| 渲染 | 卡通描边 | 外扩描边 pass，宽度与颜色可调 |
| 渲染 | 遮挡剔除 | 软件 HZB：上一帧深度降采样为金字塔（反向 Z 下 float 回读取 max），对 BVH 节点做屏幕空间遮挡测试，大物体保守保留，可开关；回读尺寸 128、隔帧构建（奇数帧沿用上次缓存），回读走 PBO 双缓冲，无 PBO 映射能力时回退同步 glReadPixels |
| 渲染 | GTAO 工作集 | 三个 FBO 由四附件 Rgba32F 改为 R8 单双附件，工作分辨率由二分之一降至三分之一，深度重建由四次矩阵乘改为标量除法 viewZFromDepth |
| 界面 | 主菜单 | 独立 MainMenu 类：标题左上、菜单项左下竖排带选中竖条，菜单项为开始游戏 / 设置 / 退出；启动画面后先进主菜单，点开始游戏才进游戏循环；背景支持 2D 贴图（cover 保持宽高比铺满裁切）与 3D 场景两种，Demo 背景取内置资源 vein_1_18 |
| 界面 | 启动画面 | 单段白底黑字「Made in / Gvtcier」，由代码绘制不依赖图片资源；不做淡入，首帧满不透明，保持后平滑淡出；未买断授权连续展示满 3 秒（对齐可视化合规标准），买断授权（--licensed）免除署名义务缩短至 1.5 秒 |
| 界面 | ESC 菜单四项化 | 继续游戏 / 设置 / 返回到菜单 / 退出到桌面；「返回到菜单」经独立信号回主菜单（主菜单与游戏循环包进外层循环，返回即重入），确认弹窗文案「确认退出到桌面」 |
| 界面 | 菜单暂停 | 菜单打开时置场景暂停位：物理、场景动画、全局与对象脚本、输入、粒子更新全部停止，脚本绘制时间步传零冻结动画；关闭时清零累加器并重置计时基准，杜绝恢复后物理补跑的时间跳跃 |
| 界面 | HUD 隐藏 | 渲染器设游戏 UI 抑制开关，在 2D 绘制唯一汇聚点拦截画布队列（引擎 UI 队列不受影响）；菜单打开期间只丢游戏 UI、保留菜单 |
| 界面 | 防连点 | 主菜单首帧丢弃点击、生效点击后 0.1s 内忽略后续点击，覆盖菜单项、键盘确认与设置页，避免切换界面当帧点击被新界面二次消费 |
| 界面 | 设置刷新 | 进设置页前构建设置项列表；切页时重置悬停、选中与滚动状态，避免鼠标位置恰落新页首行致误高亮 |
| 界面 | 设置页按模式裁剪 | 二维模式下通用页去掉运动相机与 FOV，画面页只留抗锯齿，操控页改用脚本声明的动作表并去掉鼠标灵敏度与按键预设；设置页背景不透明度零点九，暂停时可见底层定格画面 |
| 界面 | 二维时机钳制 | 主菜单停留期间不推进二维脚本；暂停菜单打开期间冻结输入并以零步长重绘，画面定格、逻辑不推进，关闭后不补发按键 |
| 渲染 | 2D 画布 | 纯 canvas 渲染（圆角矩形 / 圆 / 线 / 弧，SDF 抗锯齿 + 实例化批处理），与 3D 链互斥 |
| 渲染 | 世界画线 | 世界空间彩色线段提交，用于调试与自定义线框 |
| 渲染 | 透明度系统 | 按物体设置透明度：Object.alpha（0 到 1），alpha 小于 1 自动进透明队列；脚本 设置_属性(对象, "透明度", 值) / 获取_属性 读写，动画状态机轨道与 gmap 同样支持；另支持按 UI key 设置透明度与淡入淡出 |
| 渲染 | 字体渲染 | 打包字体经 stb_truetype 自行栅格化，不依赖系统字体安装情况，CFF 轮廓的 OTF 也能解析；字形按 96px 高分辨率栅格进图集，绘制时缩小而非放大，边缘干净；图集按需扩页，装不下自动开新页而不再丢字形；文本测量与对齐，支持中文 |
| 界面 | 命中框 | GvtHitRect 统一可点矩形：绘制即得热区（画一行 / 居中画一行 / 只量不画），设置页行控件另有均分布局；热区与可见文字或控件完全一致 |
| 界面 | 界面音效 | 悬停与按下两种反馈（7_4 掠过 / 7_3 按下），主菜单、暂停菜单、设置页共用一套 GvtUiSound；资源缺失时静默跳过，界面照常可用；开场自检会把两条的加载结果写进日志 |
| 渲染 | 字体出处 | 思源黑体 Regular / Bold 打包进 res.rc，字体族名改为 Gvtcier_Font（SIL Open Font License 1.1，可商用可嵌入） |
| 渲染 | 第三人称跟随相机 | 脚本 设置_相机目标(实体名) 让相机跟随指定实体，设置_相机偏移(x,y,z) 定后拉距离，跟随开启后相机位置 = 目标位置 + 偏移；获取_相机偏移 读回偏移，设置_相机角度 直接写 yaw/pitch；与「玩家相机 / 工程相机」模式并存，跟随为空时回到原模式 |
| RHI | 抽象层 | 缓冲区、纹理、着色器、帧缓冲、绘制调用统一封装，PassState 统一下发帧状态 |
| RHI | OpenGL 4.6 core 后端 | 桌面唯一后端 |
| RHI | OpenGL ES 3.2 后端 | 安卓后端，与 GL 后端同表同接口（Backend::Gles），引擎上层零改动切换；EGL 以 3.2 协商，不支持时回退 ES 3.0；GLES 分支为编译期门控 GVWCIER_USE_GLES |
| RHI | 像素回读抽象 | GLES 用 glMapBufferRange + glUnmapBuffer 走 PBO 回读，桌面保留 glMapBuffer |
| RHI | OpenGL 1.1 固定管线 | 26 个 GL 1.1 函数从 opengl32.dll 直接加载，与 gl4 隔离 |

| RHI | 裸 OpenGL 直通 | 脚本调用 Gv_only_OpenGL 直接驱动 RHI，绕过引擎管线 |
| RHI | MRT | 支持多颜色附件输出 |
| RHI | 着色器 | 全部 GLSL 源文件，RCDATA 内嵌，运行时加载，shader_guard 全局失败计数防静默失效 |

| RHI | GPU 能力探测 | gpu_profile 自动画质降档，支持 NVIDIA / AMD / Intel / 摩尔线程 / Apple / 高通 / 软件 |

| 模组 | 应用顺序 | 片段覆盖 → ghook 补丁 → 钩子注册，全部在主脚本文本预处理阶段完成，之后才做入口改写与顶层结构预检 |
