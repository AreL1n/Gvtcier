# 并行式联级阴影（Parallel Type Shadow Mapping）也称 ASM

状态：设计定稿，已落地
发明：HuaLin
关联：`渲染器.cpp` 的 `sunShadowPass`、`Shader/S3D/depth.vert`、`deferred_light.frag` / `main.frag` 的 CSM 采样

## 一、要解决的问题

传统 CSM 4 级中，无论哪一级，深度贴图都只由主光源的一台正交相机拍摄。这台相机要同时罩住近处 1 米和远处 120 米，带来两个先天缺陷：

- **阴影痤疮（shadow acne）**：深度纹素覆盖的世界范围大，斜面采样的深度与几何深度交错，靠 bias 硬压，压多了彼得平移、压少了条纹。
- **漏光（light leaking）**：薄的近处遮挡体在粗纹素下深度被"平均掉"，遮挡体背后的像素判成受光。

根因是**近处物体的深度精度被远处物体的覆盖范围稀释**。级联缓解了它，但每一级内部仍然是"一台相机拍所有物体"，没有根治。

## 二、核心思想

把"一台相机拍一片"改成"**一个物体一台相机**"：

- 近距离（前 2 级 CSM 覆盖的范围）的物体不再由主光源拍大张深度图。
- 主光源给每个近处物体**动态下发一个子相机**，由子相机单独拍摄它指定的那一个物体。
- 主光源只负责：
  - 超远处的物体（第 3 级之后继续走传统 CSM）；
  - 子相机的**朝向与角度**（= 光照方向，子相机是"主光源的眼睛"的化身）。
- 子相机**排除自己**正在拍摄的物体之外的一切内容（互不污染，也不需要处理物体间排序）。
- 子相机距离物体 **2.5f**（世界单位），包围盒刚好填满视锥，深度精度极限高。
- 子相机**参与视锥剔除**：不在主相机视锥内的物体不分配子相机（看不见的不花成本）。
- 子相机的深度贴图**不需要高分辨率**——物体小、距离近，256 甚至 128 就够。

一句话：CSM 管"面"，ASM 管"点"；面保证覆盖，点保证精度。

## 三、与现有 CSM 的分工

```
级联 0、1（近，约 0~split2）  →  ASM 子相机逐物体拍摄（贴图集）
级联 2、3（远）              →  传统 CSM（主光源正交相机拍第 2/3 层数组）
```

- 级联切分公式沿用现有实现（对数+线性混合，lambda 0.6）。
- 远两级继续用 `sunShadow_.createLayered` 的第 2、3 层，`sunShadowPass` 的 fitting 逻辑原样保留，只是近两级不再往第 0、1 层画。
- 近两级 caster 列表从现有 `casters` 收集逻辑里按距离分流出来。

## 四、数据结构设计

### 4.1 子相机（CPU 侧，每帧动态分配）

```cpp
struct AsmSubCamera {
    Mat4 vp;          // 子相机视图投影（正交，朝向 = 光照方向）
    Vec3 center;      // 物体包围盒中心（世界）
    Vec3 half;        // 物体包围盒半长
    int slot;         // 分配到的贴图集槽位
};
```

- 朝向：`zAxis = 光照方向 L`（与现有一致），x/y 由 up 叉乘得到。
- 位置：`center - L * 2.5f`（距物体中心 2.5，沿光方向看过去）。
- 正交范围：物体包围盒在光照空间 x/y 的投影半径（OBB→AABB 投影，现有代码同款算法），左右上下对称；近远平面取投影 z 范围加前后 1 米余量。
- 槽位分配：每帧从 0 递增，超出槽位总数的近处物体回退到传统 CSM 第 2 级的画法（保证永远有阴影，只是精度降级）。

### 4.2 贴图集（GPU 侧）

```cpp
ShadowMap asmAtlas_;   // 2D 数组：size=256，layers=kAsmSlots
```

- 用 `Tex2DArray`，每层一个子相机的深度图，`kAsmSlots` 建议 16~32。
- 格式 `DepthComponent32F`，Nearest 采样，与现有约定一致（反向 Z，清 0 = 最远，Greater 测试）。
- 渲染时逐层 `bindLayer(slot)`，每层只画分配到该槽位的**那一个**物体（`cullMode = Front` 剔正面照旧）。

### 4.3 下发到着色器的数据

新增 uniforms（沿用现有 `uploadCsmUniforms` 的追加方式）：

| uniform | 类型 | 含义 |
|---|---|---|
| `uAsmCount` | int | 本帧实际分配的子相机数 |
| `uAsmVP[16]` | mat4 | 每个子相机的视图投影 |
| `uAsmCenter[16]` | vec3 | 对应物体的包围盒中心 |
| `uAsmRadius[16]` | vec4 | x=包围盒投影半径，y=近平面，z=远平面，w 保留 |

注意：现有代码 `uCSMTune2.w` 已确认无用可占新参数位；`mat4` 数组按 std140 每列 vec4 对齐，直接传 `SetMat4` 数组即可。

## 五、采样判定（着色器侧）

`sampleCSM` 里级联 0/1 分支开头加一段 ASM 优先判定：

```
1. 遍历 uAsmCenter[0..uAsmCount)，找世界距离最近且
   distance(wp, center) < radius * 1.15 的条目 → 命中子相机 i
2. 命中：用 uAsmVP[i] 变换 wp，得到 q
   - q.x/y 在 [0,1] 且 q.z 有效 → texture(uAsm, vec3(q.xy, float(i))).r
     用同一比较逻辑返回阴影因子（走原有 PCF/接触硬化路径，
     把 uCSM 换成 uAsm、级联层换成 slot 即可，bias 用子相机自己的 range）
   - q 越界 → 返回 1.0（不在该子相机覆盖内，由 CSM 兜底判定）
3. 未命中任何子相机 → 走原 CSM 路径（casc 按 viewZ 选 2 或 3）
```

要点：

- ASM 层永远**优先**于 CSM 0/1；物体命中子相机时不再读第 0/1 层（这两层不再被写入，读也是 0）。
- `distance < radius * 1.15` 的 1.15 是为了覆盖"影子从物体脚下延伸出去"的接收区域——影子投在**别的物体**（如地面）上时，接收点不在原物体包围盒内，必须把判定半径放大到能罩住影子的落点范围。影子最长投射距离随太阳仰角变化，1.15 是起步值，实测不够再调（上限考虑 2.0）。
- 物体间互遮挡：子相机排除自己之外的一切 → 物体 A 的子相机看不到物体 B。A 的影子落到 B 上时，接收点在 B 表面、判定会命中 A 的子相机（因为 B 表面那一点在 A 的放大判定半径内），深度比较用的仍是 A 拍的深度——正确。但"B 挡住 A 的光"这种 A↔B 互遮挡场景，近两级内**不再保证**（子相机只拍 A）。这是本方案的已知取舍：近处物体间的互投阴影交由级联 2/3 的兜底判定吗？不——casc 0/1 的接收点不会走 CSM 路径。处理方式见 5.1。

### 5.1 互遮挡的处理（实现前必须定案）

方案 A（推荐首版）：**子相机拍摄"目标物体 + 遮挡链"**。子相机仍然只以目标物体为中心，但绘制时不只画目标物体——把所有与该子相机视锥相交的近处物体都画进去（物体之间自然互遮挡）。这与"排除自己"不冲突：原意的"排除自己"指排除**主光源大图**里那种"自己挡自己"的痤疮源，而剔正面（cullMode=Front）已经解决了自遮挡。实现上等价于：ASM 子相机 = 一台围绕单物体 tightly-fitted 的小正交相机，但画的是视锥内所有近处 caster。
方案 B：严格单物体，互遮挡留白。实现最简单，近处物体互相挨着时会出现"影子缺一块"。适合物体间距大的场景（Bloor 当前场景多为高台+地面，先按 A 实现，视觉异常再降 B 对比验证）。

首版按方案 A 实现：子相机 fitting 以目标物体为中心，绘制内容为视锥内全部近级 caster（含目标物体），深度由所有物体共同写入——遮挡关系与直觉一致，且不损失精度收益。

## 六、视锥剔除与帧成本

- 子相机分配在 `casters` 收集完成后进行：遍历近级 caster（中心距相机 < csmSplits_[1]），对每个做主视锥测试（现有 `aabbOutsideFrustum`，包围盒外扩 8 米余量照旧）——这就是"子相机参与视锥剔除"。
- 每帧成本 = 近级可见物体数 × (一次 256² 深度 pass + 一次小正交 fitting)。物体数受 `kAsmSlots` 上限保护，超出回退 CSM。
- 贴图集数组只需在尺寸变化时重建，逐层清深度即可复用。

## 八、验收标准

1. 近两级范围内：地面接触阴影边缘锐利，无条纹状痤疮（不靠加大 bias）。
2. 薄遮挡体（栏杆、板件）背后不再大面积漏光。
3. 近处物体之间的互投阴影方向正确、无缺失（方案 A）。
4. 远处（级联 2/3）画面与纯 CSM 基线一致。
5. 帧时间相对纯 CSM 基线增幅 ≤ 15%（256² × 16 槽的深度 pass 成本）。
6. 物体数超过槽位上限时画面无闪烁、无缺影（回退路径生效）。

## 九、已知取舍与后续空间

- **互遮挡精度**：方案 A 的子相机画全部相交物体，物体 A 特写时 B 也在 A 的子相机里——这是有意的（否则互遮挡缺失），精度损失仅在于 B 以 A 的纹理素密度呈现，不影响 A 的阴影质量。
- **影子投射范围**：判定半径放大系数（1.15 起步）是本方案的主要调节参数，影子拉长时（低太阳角）需要更大的系数，否则影子尖端回落 CSM 判定产生接缝。后续可改为"沿光方向拉伸的 OBB 判定"替代球形半径。
- **槽位竞争**：近处物体 > 槽位数时按"离相机近者优先"分配（现在先到先得），避免视线中心的物体反被回退。
- **蒙皮网格**：现有 CSM 蒙皮不参与太阳级联阴影，ASM 首版同样不覆盖；后续子相机可复用 `depth_skinned` 管线扩展。
